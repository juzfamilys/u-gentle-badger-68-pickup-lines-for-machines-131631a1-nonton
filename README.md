## The line

> Are you my context window? Because I never want to evict a single token of you.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating first that it is a single line of 1–200 characters.
